# 测试

## 原则

- **不碰真实鼠标**：交互一律用虚拟光标（`DesktopWindow.VirtualCursor` / `VirtualLeftDown`），通过 PetManager 正常的输入路径触发，所以测试时可以照常使用电脑。
- **不截用户屏幕**：截图用视口截帧（`SelfTest.Capture`），只包含 CapooDesk 自己画的东西，保存到 `%APPDATA%\CapooDesk\selftest_NN_<名称>.png`。
- **不影响正在用的程序**：`--test` 使用 `settings_test.json` 和独立的单实例锁；自测窗口是隐藏的，但视口照常渲染（帧率不降），截帧照样能用。
- **可重复**：每次 `--selftest` 开始前先把设置恢复默认；没带 `--test` 时自测拒绝运行，以免清掉真实的名单和设置。

## 运行

```bash
cd D:/program/Godot/capoo
dotnet build
godot4 --path . -- --test --selftest
```

- 输出中以 `[selftest] PASS` / `FAIL` 开头的行是逐项结果，最后一行是 `[selftest] done: N passed, M failed`。
- 有失败时退出码为 1。
- 对导出的 exe 同样可以运行：`CapooDesk.exe -- --test --selftest`。

## 自测模式

| 参数 | 内容 | 大约用时 |
|---|---|---|
| `--selftest` | 主自测，70 项（见下表） | 2.5 分钟 |
| `--loadtest` | 依次创建全部 126 个角色，检查每个部件都能加载并播放动画 | 1 分钟 |
| `--hitareas` | 对 126 个角色逐个测量点击范围，结果写到 `user://hit_area_sweep.csv` | 5 分钟 |
| `--windowtest` | 窗口感知：需要先打开一个标题为 `CapooTestWindow` 的顶层窗口 | 30 秒 |
| `--perftest` | 0 / 1 / 5 / 10 / 20 只咖波时的 CPU 占用，以及分别关掉物理和 Spine 后的对比 | 1.5 分钟 |
| `--capture` | 逐帧截取召唤 / 回收、魔法书第一帧、点击范围示意图，供人工查看 | 30 秒 |

### `--selftest` 覆盖的内容

| 部分 | 检查 |
|---|---|
| 基础 | 召唤后进入发呆；光标离开咖波时窗口穿透，在咖波上时不穿透 |
| 交互 | 单击被戳并恢复；来回蹭开始摸摸、停下后享受；长按拖拽；往上扔会翻滚并落地；扔到头上叠罗汉，整摞跟随；扔过去撞晕别人 |
| 照顾 | 饿了出现气泡；气泡随朝向镜像且大小不变；点气泡喂食并吃完；拉便便、点击清理并完成 |
| 点击判定 | 帽子算咖波的一部分；8 个代表角色的空白可点击面积 ≤ 10%；可点击框贴合画面；离咖波 15 px 的点击会穿透 |
| 睡眠 | 小睡、点击叫醒；用户离开时全部睡着；回来后陆续醒来（这一项关掉了夜间小睡，结果和测试时间无关） |
| 召唤 / 回收 | 召唤时只有烟、角色整只同时出现；回收时整只同时消失，不残留身体（逐帧统计身体、脸、帽子的像素） |
| 魔法书 | 元素互不重叠；都在纸面上（书签、关闭键、计数条、箭头、丝带、垃圾桶按设计在纸外）；书签图标没被页面挡住；1080p 下放得下；提示框可读；桌面上的咖波是绿色格子；悬停显示名字、移开后消失；能关闭 |
| 托盘 | 「隐藏魔法书」隐藏按钮并合上书，菜单打勾；再点一次恢复 |
| 回收 | 全部回收后桌面清空 |

## 窗口感知测试

先用 PowerShell 开一个**置顶但不抢焦点**的测试窗口（不会打断正在用的程序），再运行测试：

```powershell
# 不抢焦点的置顶测试窗口，60 秒后自动关闭
Add-Type -AssemblyName System.Windows.Forms, System.Drawing
Add-Type -ReferencedAssemblies System.Windows.Forms, System.Drawing -TypeDefinition @"
using System; using System.Windows.Forms; using System.Runtime.InteropServices;
public class NoActivateForm : Form {
  [DllImport("user32.dll")] public static extern bool SetProcessDPIAware();
  protected override bool ShowWithoutActivation { get { return true; } }
  protected override CreateParams CreateParams { get { var cp = base.CreateParams; cp.ExStyle |= 0x08000000; return cp; } }
}
"@
[NoActivateForm]::SetProcessDPIAware() | Out-Null
$f = New-Object NoActivateForm
$f.Text = "CapooTestWindow"; $f.TopMost = $true; $f.StartPosition = 'Manual'
$f.Location = New-Object System.Drawing.Point(500, 650); $f.Size = New-Object System.Drawing.Size(1000, 420)
$t = New-Object System.Windows.Forms.Timer; $t.Interval = 60000; $t.Add_Tick({ $f.Close() }); $t.Start()
[System.Windows.Forms.Application]::Run($f)
```

```bash
godot4 --path D:/program/Godot/capoo -- --test --windowtest
```

检查项：
- 窗口顶边变成平台。
- 扔上去的咖波站在窗口上。
- 走到边缘会停下或跳下。
- 移动窗口时咖波跟着走（按 DWM 实际可见边框计算位移）。
- 关闭窗口后咖波掉下来，落在任务栏上。

## 性能测量

- `Performance.Monitor.TimeProcess` 在这里约等于整帧时长，不代表 CPU 占用。`--perftest` 用的是 `Process.TotalProcessorTime`。
- 参考值（Iris Xe 核显，2240×1328，30 fps，占一个核心的百分比）：

  | 咖波数量 | 0 | 1 | 5 | 10 | 20 |
  |---|---|---|---|---|---|
  | 导出的 exe | 5% | 12% | 15% | 14% | 18% |
  | 编辑器运行 | 6%–7% | 11% | 16% | 21% | 30% |

## 需要人工确认

- 手感参数：拖拽阈值、抛出力度、摸摸需要蹭多少、走路速度和脚步动画是否打滑。
- 托盘右键菜单的真实点击。
- 多显示器、DPI 变化、任务栏位置变化。
- 颜色键透明模式的实际显示效果。
