# 用户手册

## 安装与运行

- 程序就是一个文件：`CapooDesk.exe`（约 150 MB，自带 .NET 运行时和全部素材），放在任意文件夹里双击运行即可，不需要安装。
- 第一次运行会在任务栏上方出现一只咖波，屏幕右下角出现一本可以拖动的蓝色魔法书。
- 程序同一时间只能开一个，再次双击不会开出第二个。
- 退出：托盘图标右键 →「退出」，或者魔法书设置页的「退出」。

## 和咖波玩

| 操作 | 效果 |
|---|---|
| 单击咖波 | 戳它一下，会有各种表情反应 |
| 鼠标在咖波身上来回蹭 | 摸摸它，冒爱心；停下来后它会很享受 |
| 按住咖波 0.25 秒或拖动 | 拎起来 |
| 拖着甩出去再松手 | 扔出去：往上扔会翻滚，摔得重会晕；砸到别的咖波会把它撞晕 |
| 扔到别的咖波头上 | 叠罗汉，最多 12 层；最下面的会驮着一摞走，最上面的过一会儿自己跳下来 |
| 点头上的碗气泡 | 喂食（咖波饿了时出现） |
| 点头上的扫帚气泡，或直接点咖波 | 扫便便 |
| 点睡着的咖波 | 叫醒 |
| 右键咖波 | 小菜单：名字、摸摸、喂食、睡觉 / 叫醒、回收 |

咖波会自己做的事：
- 在任务栏上走、跑、冲刺、发呆。
- 站在其他窗口的顶边上。窗口移动时它跟着走；窗口关掉、最小化或被挡住时会掉下来；走到窗口边缘时可能跳下去。
- 时不时饿了或想拉便便（可以在设置里调频率或关掉）。不理它也没有惩罚，过一会儿气泡自己消失、便便自己清理。
- 你离开电脑一段时间（默认 10 分钟）后陆续睡着，你回来后陆续醒来。夜里（23:00–7:00）更爱打盹。
- 有程序全屏运行（游戏、视频）时自动隐藏，并把帧率降到最低。

## 魔法书

单击魔法书按钮打开或合上（按住可以把按钮拖到别处，位置会被记住）。也可以左键单击托盘图标。

魔法书左边有两个书签：

### 咖波图鉴（猫脸书签）

- 每页 18 格，共 7 页，126 只咖波全部可以召唤。
- **点一格**：召唤这只咖波到桌面上。同一只可以召唤多只。
- **鼠标停在格子上**：格子出现黄色边角，上方冒出名字气泡，缩略图动起来。
- **绿色格子**：这只咖波正在桌面上。
  - 右下角的小按钮回收一只。
  - 左上角数字表示有几只（2 只以上才显示）。
- 左上方「桌面上 n / m」是当前数量和上限。满了再点会提示「满啦」。
- 左右下角的大箭头翻页，红丝带上是页码，丝带旁的垃圾桶回收全部咖波。

### 设置（齿轮书签）

左页用 ◀ ▶ 调：

| 项 | 可选值 | 说明 |
|---|---|---|
| 音效 | 静音、10%–100% | 点击、召唤、落地、吃东西等音效的音量 |
| 大小 | 25%–100% | 咖波的大小 |
| 数量 | 1–50 只 | 桌面上最多几只 |
| 帧率 | 30 / 60 | 帧率上限 |
| 透明 | 逐像素 / 颜色键 | 窗口透明的方式，见下面「常见问题」 |
| 饿/便便 | 关 / 少 / 中 / 多 | 多久饿一次、拉一次（少：约 40/50 分钟，中：15/20 分钟，多：5/7 分钟） |
| 离开后睡 | 1–60 分钟 | 多久不碰电脑后咖波开始睡觉 |

右页勾选：

| 项 | 说明 |
|---|---|
| 会睡觉 | 关掉后咖波不再睡觉 |
| 夜里多打盹 | 23:00–7:00 更爱打盹 |
| 站在窗口顶上 | 关掉后咖波只站在任务栏上 |
| 叠罗汉 | 关掉后扔到别人头上不会叠起来 |
| 全屏时隐藏 | 有程序全屏时隐藏咖波 |
| 低功耗 | 没人理咖波时把帧率降到 30 |
| 总在最前 | 咖波显示在所有窗口前面 |
| 书本按钮 | 是否显示魔法书按钮（和托盘的「隐藏魔法书」是同一个开关） |
| 开机启动 | 开机自动运行（写入当前用户的启动项；只有 exe 版本能勾） |

下面的「怎么玩」打开操作说明，「退出」关闭程序。

## 存档

- 设置和桌面上的咖波（种类、位置、朝向）保存在 `%APPDATA%\CapooDesk\settings.json`。
- 退出时保存，运行中每 60 秒也会自动保存一次。
- 删掉这个文件即可恢复默认设置（下次启动只有一只咖波）。
- 同一目录下的 `logs\` 是运行日志，遇到问题时可以附上。

## 常见问题

**咖波背后是一块黑色 / 整个屏幕变黑**
显卡驱动不支持逐像素透明。到设置里把「透明」改成「颜色键」。颜色键模式下咖波身上纯黑的像素点不中，这是这种模式的限制。

**点咖波旁边的空白处没反应 / 点到了后面的窗口**
这是正常的：只有咖波画出来的部分和界面能点，其余地方的点击会穿透到桌面和其他程序。

**咖波不见了**
- 先看托盘的「隐藏咖波」有没有打勾。
- 再看是不是有程序在全屏运行（设置里的「全屏时隐藏」）。
- 咖波可能被扔到了屏幕边缘，可以从魔法书里回收后重新召唤。

**开机启动勾不上**
只有导出的 `CapooDesk.exe` 能设置。从 Godot 编辑器运行时这一项是灰的。

**有多个显示器**
目前咖波只在主显示器上活动。

**电脑会不会变卡**
平时 1–5 只咖波大约占一个 CPU 核心的 10%–15%（整机 1% 左右）；没人理时帧率降到 30；全屏程序运行时几乎不占资源。
